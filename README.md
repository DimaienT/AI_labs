Сделал лабу 2, задача была провести EDA по датасету StudentsPerformance — 1000 строк, 8 колонок, целевая переменная `math score`. Описал постановку как регрессию, построил распределение целевой переменной (унимодальное, 81 уникальное значение, центр около 66, небольшой левый скос), вывел `describe()` и `info()`, проверил пропуски и дубликаты, построил гистограммы пяти категориальных и двух числовых признаков, а также зависимость балла от каждого признака и extra-часть с heatmap-ами по парам признаков.
